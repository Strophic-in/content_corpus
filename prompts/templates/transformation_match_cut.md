## Template: Transformation / Match-Cut Reveal
Before/starting state → transition cue → reveal → optional explanation. The "before" and
"reveal" shots are matched: describe the same camera position, framing and subject placement in
both `visual`s, so only the state changes. The reveal shot's `transition` is "zoom", "whip" or
"flash" — the cue. A short `text` may name each state ("Day 1" / "Day 100"). If the before/after
is illustrative rather than real evidence, `label` it "Illustration".
