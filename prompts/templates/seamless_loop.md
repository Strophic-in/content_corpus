## Template: Looping Reel / Seamless Loop
Visual setup → an action or reveal → a return to the opening frame. 1-3 shots, 5-15 s in all. The
last shot's `visual` ends where the first one begins — the same framing, the same position of the
subject, motion continuing in the same direction — so the replay feels continuous (the final
half-second is blended into the first frame automatically). A short `text` may run on the first
shot; avoid anything that reads as an ending ("the end", a call to action).
